# ONE MORE WAY. Закулисная история китайского киберспорта

ONE MORE WAY представляет собой первую книгу, документирующую двадцать лет закулисной истории китайского киберспорта, с 1998 по 2017 год. Автор BBKinG (Лю Ян) объехал 30 городов и взял интервью у 67 участников событий.

Русская версия пока содержит только один пилотный перевод. Остальные главы будут добавляться постепенно.

Полный текст книги доступен в [китайском оригинале](../zh/index.md), также есть [английская версия](../en/index.md).

## Переводы

- [Пусть дорог будет больше: как выжил китайский киберспорт](one-more-way-tedx-2015.md). Выступление автора на TEDxSuzhou 2015: как китайский киберспорт после запрета игровых телепередач в 2004 году раз за разом искал собственную дорогу, от P2P-трансляций до модели «Youku + Taobao».
