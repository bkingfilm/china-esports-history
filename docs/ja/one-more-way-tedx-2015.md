よく人に聞かれます。eスポーツとはいったい何なのか、と。

実はとても簡単です。eスポーツとは、「人と人とが競い合えば、その楽しみは尽きない」という営みを電子化したものだと私は考えています。ただし、公平さと公正さ、そして契約精神が前提でなければなりません。

ですから、一部の人とは考えが違うのですが、私は、どんなゲームでもeスポーツの形式を作り出せるし、誰でもeスポーツ選手になれると考えています。私たちの周りを見てください。年配の方はオンラインでドウディジュー(中国のトランプゲームです)やブリッジを楽しんでいます。子どもたちは並んで座り、iPadのアングリーバードで点数を競っています。女の子たちは体感ゲームで二人でダンス対決をし、若者たちはチームを組んでDotaやリーグ・オブ・レジェンドをプレイしています。これからますます完成度が上がっていく3Dバーチャル技術のゲームもあります。こうした種目が、公平さと公正さと契約精神という前提のもとで発展してさえいけば、大会、スター選手、クラブ、メディア、配信プラットフォームといった複雑なeスポーツの体系がそこから育っていくのです。

これが私の理解するeスポーツです。話せば1分もかからずに終わってしまいますが、その裏には、世界中の数え切れないeスポーツ人による十数年の苦しい模索と挑戦があります。

1999年、韓国の人たちは世界初の専門ゲームテレビ局OngameNetを設立しました。今もなお有名なOGN(オンゲームネット)です。同じ年に韓国eスポーツ協会KeSPAも設立しています。つまり韓国は、1999年の時点で次のようなeスポーツのモデルを作り上げていたのです。

**テレビ局 + eスポーツ + KeSPA**

これは非常に強力なモデルです。じっくり分析してみると、テレビ局は生まれながらに宣伝チャネルと収益化の力を持っています。eスポーツ大会が製品となり、KeSPAが業界のルールを固める。だからこそ、鎖の環がひとつひとつかみ合い、安定して発展していけたのです。

しかも韓国のゲーム専門チャンネルの普及率は非常に高く、2006年、OGNは韓国で1300万を超える世帯に接続されていました。この年の韓国の総人口は4700万人余りです。さらに韓国政府の支援もあり、eスポーツ大会のスポンサーは大韓航空、サムスン、現代といった大企業でした。幅広い大衆的基盤に、完成されたビジネスモデルが重なる。韓国のeスポーツは最初から好循環の状態に入っていたのです。

同じ時期の中国のeスポーツも、2004年までは非常に速く発展していました。WCG、CPL、ESWCといった国際大会を通じて、私たちは韓国eスポーツの商業的運営の成功を目の当たりにし、彼らのモデルこそ当時最良のモデルだと考えていました。

ですから2003年11月18日、中国の国家体育当局がeスポーツを中国で99番目のスポーツ種目に認定したとき、私たちは本当にうれしかったのです。ひとつには、韓国eスポーツのモデルをようやく大手を振って中国で立ち上げられるようになったからです。もうひとつには、中国の多くの衛星テレビ局がすでにゲーム番組を開設していたからです。旅遊衛視の《遊戯東西》、上海テレビの《遊点瘋狂》、西安テレビの《ゲーム倶楽部》、CCTV5の《電子競技世界》などがそうで、しかもこれらの番組の視聴率はいずれも上位に入っていました。あの瞬間、中国のeスポーツは比類のない資源と市場の将来性を手にしていたと言えます。

そのすべてが、2004年4月12日に止まりました。その日、中国の放送行政当局である広電総局が「パソコン・オンラインゲーム類番組の放送禁止に関する通知」を出し、先ほど挙げた番組はすべて打ち切られました。それはつまり、その瞬間から、韓国eスポーツが歩んだあの道は中国では完全にふさがれた、ということでした。

幸いなことに、中国のeスポーツファンもeスポーツ人もあきらめませんでした。私たちは新しい道を見つけました。それは当時の私たちにとって、唯一の道でもありました。

**インターネット + eスポーツ**

とはいえ、どう歩けばいいのか。当時の私たちにはよく分かっていませんでした。それでも道が完全に閉ざされることはなく、新しいインターネット技術が現れたのです。

P2Pストリーミング配信技術といいます。簡単に言えば、インターネット上の動画は見る人が多ければ多いほど速度が上がる、という技術です。2004年には、この技術を核とするPPLiveやPPSといった配信プラットフォームが中国国内にも登場し、中国のeスポーツも新しいモデルを見つけました。

**P2P配信プラットフォーム + eスポーツ大会 + スポンサー**

まさにこのモデルのおかげで、中国のeスポーツファンは2005年から、家やネットカフェに座ったまま、中国のみならず世界レベルのeスポーツの試合を見られるようになりました。特に2005年と2006年のWCG世界決勝です。WEクラブの李暁峰(リ・シャオフォン, Sky)選手がWCG2連覇を成し遂げ、国旗を身にまとって表彰台に立ったあの瞬間を、世界中のeスポーツファンが同時に見ていました。それからというもの、企業へ協業の話をしに行くとき、ようやく最初の1時間を「eスポーツとは何か」の説明に費やさずに済むようになったのです。

しかし客観的に言えば、このモデルは時代の制約をあまりに大きく受けていました。インターネットの利用者がこれだけ育った今でさえ、オンラインでライブ配信を見る視聴者の数は、従来のメディアに比べてまだ大きな差があります。ましてや10年前は言うまでもありません。

ですからこのモデルのもとで、eスポーツは長い間、食うや食わずでどうにか生きながらえるだけで、発展どころではありませんでした。

では、この時期にeスポーツが一番ゆとりを持って生きられたモデルは何だったのか。皆さん、当ててみてください。

**金持ちの二代目モデル**

笑わないでください。eスポーツを心から愛したこの金持ちの二代目たち、中国で「富二代(フーアルダイ)」と呼ばれる人たちがいなければ、中国のeスポーツはあの一番苦しい時期を乗り越えられなかったかもしれません。

ただ、このモデルにも大きな問題がひとつありました。不安定なのです。このお金は、途絶えるとなればその日に途絶えます。

そして2008年、世界金融危機が訪れたとき、スポンサーはなく、宣伝チャネルは狭く、収益化の手段もほとんどなかったeスポーツは、再び暗闇の中へ転げ落ちました。多くのeスポーツ組織が散り散りになり、多くのeスポーツ人が他の業界へ移らざるを得ませんでした。

2008年から2010年までの3年間、中国のeスポーツ人は大変な苦労をしました。しかし今振り返れば、それは十分に価値のあるものでした。あの3年間の業界全体の不況があったからこそ、eスポーツ人もeスポーツファンも、ひとつの問題を深く思い知ったのです。この業界は理想だけでは発展していけない。生き延びるには、自分たちの製品、自分たちの宣伝チャネル、自分たちの収益モデルを持たなければならない。中国の伝統話芸「相声」の演者、郭徳綱(グオ・ドーガン)が言うように、まずしっかり生きてこそ、発展を語れるし、大きくなることも語れるのです。

ですから2010年、金融危機が過ぎ去った後になって、中国のeスポーツはようやく成熟し始めたのだと、私個人は考えています。

この年にはいくつか非常に重要な出来事がありました。2010年12月8日、優酷(ヨウクー、Youku)が上場しました。上場前から優酷はゲームチャンネル、特にeスポーツを強く押し出していて、Dotaの引退選手や解説者の多くが優酷で自分のチャンネルを開き始めました。

同じくこの年、共同購入サイトという概念が盛り上がり、ブラウザゲームの共同運営というモデルが現れました。そして最も重要な点として、1990年代生まれの世代が20歳になったのです。

簡単に言えば、この年、eスポーツには突然新しい宣伝チャネルができただけでなく、収益化の手段も大きく増えました。

2011年、あるゲームアパレルブランドがありました。創業者もeスポーツファンで、アパレルの資源をたくさん持っていました。彼はeスポーツと自分の資源を組み合わせて、ゲームの図柄をプリントした服を作り、有名な解説者に宣伝を頼みました。するとその解説者がタオバオ(淘宝)にネットショップを開いたところ、思いがけず最初の月で月商30万元に達し、その後も毎月倍々で伸びていったのです。

皆は突然気づきました。eスポーツはこんなふうにもやれるのか、と。そこで多くのeスポーツスターや解説者が次々と自分のタオバオショップを開き、物を売り始めました。最初はeスポーツと関わりの深いマウスやキーボードといった周辺機器でしたが、その後は品目がどんどん増え、今では衣類、周辺機器、お菓子だけでなく、かばん、生活用品、旅行商品、さらには大人向けの商品まであります。その中に、皆さんがよく耳にする「ロウソンビンモデル」があります。ロウソンビンは肉でんぶ入りの中国式焼き菓子です。ロウソンビンモデルを笑う人は多いのですが、私は、ロウソンビンモデルの成功は中国eスポーツの新しいモデルがここに誕生したことを意味すると考えています。

**優酷 + タオバオ + eスポーツ**

私個人は、このモデルの登場には時代を画する意味があると考えています。私はこれを「自らの注目度の収益化」と呼んでいます。中国のeスポーツはこのときから、自分の宣伝チャネルを持ち、自分の製品と自分の収益化の方法を持ったのです。この瞬間から、スポンサーがいなくても、金持ちの二代目がいなくても、eスポーツは生きていけるようになりました。

ところがちょうどこのころ、長年くすぶっていたもうひとつの矛盾がついに火を噴きました。

私はそれを、中国eスポーツのバブル戦争と呼んでいます。

このバブル戦争は、中国eスポーツが歩んできた17年の間に何度も起きました。中でも最大のものは、2010年、Dotaの時代に起きています。eスポーツ業界の示す影響力がどんどん大きくなり、多くの資本が狂ったように流れ込んできたからです。

彼らが入ってきて最初にやったのは、この業界の核心的資源であるeスポーツ選手の奪い合いでした。当時の引き抜き合戦はもはや常軌を逸していて、彼らは契約の違約金を無視しました。たとえば、クラブが選手と結んだ契約書に違約金50万元、100万元と書いてあっても、彼らはそのお金をそのまま顔に投げつけて、「この選手はもらっていく」と言い、人を引き抜いていったのです。

このバブル戦争が最後まで行き着いたとき、参戦したクラブはみな、自分たちの全員が敗者だったことに気づきました。使ったお金がまるで回収できなかったからです。そこで人々はようやく意識し始めました。こんなやり方を続けてはいけない。eスポーツは契約精神を立て直し、ルールを持たなければならない、と。

こうして2011年、中国で最大手のプロeスポーツクラブ12団体が手を組み、ひとつのeスポーツ連盟を設立しました。

それから5年近い模索と改善を経て、今の中国eスポーツは安定した業界の構図を形づくっています。連盟は話し合いと交渉の土台を提供しました。今では各シーズンの終了後に専用の移籍ウィンドウ期間があり、この期間中、クラブのエージェントは他クラブの責任者を訪ねて選手の移籍を協議できます。選手に不正行為や代理プレイ、消極的な試合があった場合、さらにはイベント出席時の服装や言動が不適切だった場合まで、連盟には具体的な条文による規定があります。

2014年8月、つまり昨年、アメリカのアマゾンがeスポーツ配信プラットフォームのTwitchを9億7000万ドルで買収すると、Twitchに似た配信プラットフォームが中国で次々と人気を集め、資本と大衆によるeスポーツへの新たな関心の波がもう一度巻き起こりました。eスポーツのモデルはさらに複雑になっています。これについては、数年後にあらためて評価することにしましょう。

未来については、eスポーツは、映画産業が生まれたばかりのころと同じ位置にあると私は考えています。eスポーツは、大衆の余暇と娯楽にかかる費用とハードルを大幅に下げました。しかも映画を見るよりも手軽で、安く、双方向性も強いのです。これらはインタラクティブエンターテインメントの新しい革命をもたらし、そこから巨大な娯楽産業の構図が育っていくはずです。

最後に申し上げたいのは、今日のこの講演は、eスポーツがどれほど素晴らしく完璧か、皆さんもぜひ遊びに来てください、と言うためのものではない、ということです。違います。eスポーツはこの社会のひとつの縮図にすぎず、私たちがまだ解決策を探している問題もたくさんあります。

たとえば、私たちは保護者からの電話をよく受けます。うちの子が学校をやめてeスポーツをやると言っている、手を尽くしたがどうしても止められない、eスポーツのスターに出てきてもらって子どもを説得してほしい、という内容です。私たちはたいてい、その説得を手伝います。

なぜなら、私自身がかつてそういう子どもだったからです。だから分かるのですが、大部分の子どもは、心の底では、自分がeスポーツという道に向いていると強く確信しているわけではありません。学業でつまずいた後、無意識のうちに自分の新しい出口を探しているだけなのです。

しかし、まさにここに問題の根っこがあります。大学入試「高考(ガオカオ)」という一本の狭き門のほかに、私たちの社会が子どもたちに用意している道はあまりに少ないのです。だからこそ、華やかでにぎやかに見えるパソコン、インターネット、ゲームが、慌てふためく中で子どもがつかむ、わらにもすがる思いのよりどころになってしまうのです。

私は実のところ、その子がeスポーツを選ぶかどうかは気にしていません。私が気にかけているのは、その子が選んだその道を本当に好きなのか、自分に合っているのか、そしてどう歩けばいいのか分かっているのか、ということです。

そして私たちの世代の責任は、新しい道を懸命に探して切り開き、新しい文化を受け入れて育てられる世界を作ることです。次の世代が思い切って考え、思い切って選び、やり遂げられるように。健全で前向きなサブカルチャーのどれもが、芽を出して育つチャンスを持てるように。

これが、この講演のすべての目的です。ご清聴ありがとうございました。
