# ONE MORE WAY 中国eスポーツの舞台裏史(日本語版)

《ONE MORE WAY》は、1998年から2017年までの20年間、中国eスポーツの舞台裏で起きたことを記録した初めての書籍です。著者のBBKinG(劉洋、リュウ・ヤン)は30の都市を訪ね歩き、67人の当事者へのインタビューを重ねて、この本を書き上げました。

日本語版は現在、試験的な翻訳としてこの一篇のみを公開しています。以降の章も順次追加していく予定です。

- [中国語完全版](../zh/index.md)
- [英語版](../en/index.md)
