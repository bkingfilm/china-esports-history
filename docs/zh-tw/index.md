# ONE MORE WAY

**中國電競幕後史**

《ONE MORE WAY》是第一部記錄中國電子競技前二十年（1998 年至 2017 年）幕後故事的書。作者 BBKinG（劉洋）花三年走遍海內外 30 座城市，訪談 67 位造就這個圈子的人，選手、主播、賽事主辦、俱樂部老闆、記者都在裡面。

全書可以看[簡體中文版](../zh/index.md)。繁體中文版集中放在這一區，好讓章節持續增補而不動到簡體原文的檔案。[英文版](../en/index.md)與[韓文版](../ko/index.md)已經全書完成。

## 這個版本怎麼處理用字，先說清楚

**書裡的人名、地名、機構名、賽事名、公司名與電競 ID 一律保留大陸原本的說法，只轉字形。** 這本書寫的是大陸電競圈的事，把說法改成台灣習慣就失真了。

遊戲名同樣保留原名，首次出現時在括號裡附上台灣通行譯名，例如《星際爭霸》（臺譯《星海爭霸》）、《帝國時代》（臺譯《世紀帝國》）。大陸特有的制度與事物，像甲 B、乙級、下崗、單位，照原稱不換成台灣的對應說法。

用詞則照台灣習慣在地化，網路、軟體、資訊、螢幕、伺服器這類一般詞彙都換成台灣的講法。人物對話與直接引語只轉字形，不改說話的口氣。
