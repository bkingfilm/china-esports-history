# ONE MORE WAY

**中國電競幕後史**

《ONE MORE WAY》是第一部記錄中國電子競技前二十年（1998 年至 2017 年）幕後故事的書。作者 BBKinG（劉洋）花三年走遍海內外 30 座城市，訪談 67 位造就這個圈子的人，選手、主播、賽事主辦、俱樂部老闆、記者都在裡面。

全書可以看[簡體中文版](../zh/index.md)。繁體中文版集中放在這一區，好讓章節持續增補而不動到簡體原文的檔案。[英文版](../en/index.md)與[韓文版](../ko/index.md)已經全書完成。

## 這個版本怎麼處理用字，先說清楚

**書裡的人名、地名、機構名、賽事名、公司名與電競 ID 一律保留大陸原本的說法，只轉字形。** 這本書寫的是大陸電競圈的事，把說法改成臺灣習慣就失真了。

遊戲名同樣保留原名，首次出現時在括號裡附上臺灣通行譯名，例如《星際爭霸》（臺譯《星海爭霸》）、《帝國時代》（臺譯《世紀帝國》）。大陸特有的制度與事物，像甲 B、乙級、下崗、單位，照原稱不換成臺灣的對應說法。

用詞則照臺灣習慣在地化，網路、軟體、資訊、螢幕、伺服器這類一般詞彙都換成臺灣的講法。人物對話與直接引語只轉字形，不改說話的口氣。

## 章節

（本區正在逐章增補，每一章都是等待校對的工作稿。）

- [序章 讓路更多一些 我在 TEDx 講中國電競](one-more-way-tedx-2015.md)，作者 2015 年在 TEDxSuzhou 的演講。中國電競一度想照搬韓國那套電視加協會的模式，2004 年廣電總局一紙禁令把路堵死，之後靠 P2P 直播、富二代掏錢、優酷與淘寶，一路重新找活法的十七年（等待校對的工作稿）
- [中國電子競技幕後史 自序](00-authors-preface.md)，作者 2013 年寫下的全書自序。為什麼要寫幕後人員而不是明星，什麼樣的遊戲才算電子競技項目，為什麼說當年國家沒理電競反倒是好事，以及星際、CS、WAR3、DOTA 各自約五年的生命週期（等待校對的工作稿）
- [一 從星際爭霸說起](01-starting-with-starcraft.md)，全書第一章。1998 年到 2002 年星際爭霸在中國怎麼熱起來的，BN 平臺上的第一批玩家、軍團式的大戰隊、CSA 與各地戰網的出現、寫戰報的個人媒體，以及作者從中歸納出的那條「核心、擴散、賽事、媒體」鏈條（等待校對的工作稿）
- [二 電子競技的百家爭鳴](02-hundred-schools-of-esports.md)，全書第二章。2000 年前後那場電競的思想大爆炸。red-apple 拿到騰圖電子出版社一百萬做電競並寫下一份超前的發展規劃，洪哲夫從 ESWC 帶回國外的辦賽經驗，19 歲的 WE.KinG 裴樂在上海總統套房經歷了一趟夢碎之旅，還有星際爭霸 1.04 版外掛爆發後韓羽良提出的裁判組與職業化設想（等待校對的工作稿）
- [三 電子競技新聞網站的革新](03-esports-news-sites-reinvented.md)，全書第三章。CS 媒體從星際媒體手上接棒，Cschina 一度是最大的 CS 網站，後來居上的 Ccsk 靠遍及各地的記者站與撐得住的論壇，在 2002 年 E|zero 26space 被取消 WCG 韓國總決賽資格的風波裡完成翻盤，文末附作者 2004 年寫的 Ccsk 訪談（等待校對的工作稿）
- [四 中國電子競技對戰平臺興衰錄](04-rise-and-fall-of-gaming-platforms.md)，全書第四章。作者認為中國電競第一個穩定盈利的商業模式是對戰平臺。聯眾棋牌吃到第一波紅利，星際時代冒出近百個模仿暴雪戰網的私服，亞聯 2001 年強推收費把玩家一夜之間趕光，浩方靠電信機房快速鋪伺服器衝到近百萬同時線上後被盛大收購，陳歐帶著 GG 平臺遠走新加坡變成 Garena，VS 平臺趕上 DOTA 的好時候又從 2010 年開始衰落（等待校對的工作稿）
- [五 CEG 的故事](05-story-of-ceg.md)，全書第五章。2003 年電子競技被國家體育總局列為第 99 個正式體育項目，全國電子競技運動會 CEG 隨之開辦。作者拆的是這盤棋的底牌：華奧星空由體育系統與香港中信泰富合資成立，一邊有內容一邊要電訊傳媒管道，衝的是 2008 年北京奧運；廣電總局 2004 年一紙禁播令抽掉轉播權，CEG 改用中國足球那套主客場聯賽，八個賽區各撥 100 萬要俱樂部自己商業化，結果場館裡常常只坐著選手的親友（等待校對的工作稿）
- [六 StarsWar 的電競賽事娛樂化探索](06-starswar-esports-entertainment.md)，全書第六章。作者本人就在 StarsWar 團隊裡，所以這一章先從自黑寫起。Replays.net 創始人 Zax 靠包容把一群偏執狂聚在一起，在美國騎單車送外賣的留學生許雲波三個月吃掉美國 IGE 一半市場，回頭把戰隊、網站、賽事湊成鐵三角；2005 年第一屆 StarsWar 在盧灣體育館坐滿 2500 人，第二屆換到四千人場地，開賽前三週才被告知缺批文，而門票已經賣掉一萬多張；末尾談盃賽模式為何失去活力，以及賽事為什麼要往娛樂化走（等待校對的工作稿）
