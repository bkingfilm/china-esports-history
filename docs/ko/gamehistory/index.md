# 중국 게임의 이면사

저자가 계획했던 또 한 권의 책으로, 시야를 e스포츠에서 게임 산업 전체로 넓힌 것이다. 이 기획은 저자가 다큐멘터리 제작에 뛰어들면서 중단되었다. 남아 있는 것은 서문과 본문 8편, 번외 1편으로 모두 10편이며, 전부 [중국어 간체판](../../zh/gamehistory/index.md)으로 볼 수 있다.

## 지금까지 번역된 글

- [서문](00-foreword.md), 일 년 반 동안 50여 명을 인터뷰한 끝에 저자가 왜 이면사의 범위를 e스포츠에서 게임 산업 전체로 넓혔는지를 짚는다 (작업본, 검토 대기)
- [제1장. 지촨밍징(吉川明静) '장밍징'과 일본 게임의 인연](01-zhangmingjing-japanese-games.md), 상하이 원먀오 시장에서 일본 게임 카트리지를 뒤지던 중고등학생이 《사쿠라 대전》의 중국어화를 맡고 《체인 크로니클》을 운영하기까지 (작업본, 검토 대기)

## 번역 개선에 참여하기

한국어 장은 작업본으로 공개하며, 장 단위로 검토를 거친다. 각 장 첫머리에 현재 검토 상태를 밝혀 두었다. 오역, 잘못된 표기, 사실 오류를 발견하시면 [이슈를 열어](https://github.com/bkingfilm/china-esports-history/issues/new) 주시거나 풀 리퀘스트를 보내 주세요. 수정 제안은 언제든 환영하며 기여자로 기록한다.
