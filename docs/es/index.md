# ONE MORE WAY: la historia entre bastidores de los esports chinos

ONE MORE WAY es el primer libro que documenta los veinte años entre bastidores de los esports chinos (1998 a 2017). Para escribirlo, el autor BBKinG (Liu Yang) recorrió 30 ciudades y entrevistó a 67 protagonistas de esa historia.

La versión en español es un proyecto en marcha: por ahora solo contiene esta traducción piloto, y los demás capítulos se irán añadiendo poco a poco.
